# 视觉 / 交互设计的判断框架

## 核心

设计不是凭感觉,是**在密集约束下高速做判断**。
框架不是步骤,是约束。

## 四层

新点子来了,过这四层:

1. **目标层** — 这个设计要让读者产生什么?
2. **约束层** — 不能违背什么?
3. **方案层** — 还有别的方案能解决同一个问题吗?
4. **判断层** — 比下来哪个最贴目标和约束?

## 本项目约束

- 视觉极度克制,文字才是最珍贵的资产
- 顺畅 = 对了 / 哇好酷 = 错了
- 线下温度感(读者"走进去",不是"被指着看")
- 不要中国山水画
- 不要 AI 翻译腔 / 学术腔
- 反对花哨动效

## 失败信号

- "这个看起来好酷" — 哇好酷 = 错了
- "这个范本太好了我要全部复制" — 没过约束筛
- "我现在很兴奋" — 慢一拍
- 灵感没有解决任何具体问题 — 没有目标层
- 在多个候选间反复横跳 — 约束没说清,或目标不明确
